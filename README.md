# ⏱️ Ultimate Timer

Современный, красивый и многофункциональный веб-таймер в одном файле.

## ✨ Возможности

- **2 режима работы**:
  - Таймер обратного отсчёта.
  - Секундомер.
- **Гибкая настройка времени**:
  - Ручной ввод минут и секунд.
  - Быстрые пресеты: `5`, `15`, `25 (Pomodoro)`, `50` минут.
- **Удобное управление**:
  - `Старт`, `Пауза`, `Сброс`, `Круг`.
- **Визуальная индикация**:
  - Круговой прогресс-бар.
  - Крупный цифровой дисплей.
- **Дополнительные функции**:
  - Список кругов (laps).
  - Переключение светлой/тёмной темы.
  - Звуковой сигнал завершения.
- **Адаптивный интерфейс** для десктопа и мобильных устройств.

## 🚀 Быстрый старт

1. Склонируйте репозиторий или скачайте файлы.
2. Откройте `index.html` в любом современном браузере.

> Ничего устанавливать не нужно — приложение работает полностью на HTML/CSS/JavaScript.

## 🎯 Для чего подходит

- Фокус-сессии и Pomodoro.
- Тренировки и интервальные задачи.
- Учёба, работа и контроль времени в повседневных делах.

## 📌 Примечание

Если звуковой сигнал не воспроизводится, убедитесь, что браузер разрешает звук для текущей вкладки и страница уже получила пользовательское взаимодействие (клик по кнопке).
