# ⏱️ Ultimate Timer

Современный веб-таймер в одном маленьком приложении: таймер обратного отсчёта, секундомер, Pomodoro, интервальные тренировки и PWA-режим.

## ✨ Возможности

- **4 режима работы**:
  - Таймер обратного отсчёта.
  - Секундомер с кругами.
  - Pomodoro с фокус-сессиями, настраиваемыми короткими и длинными перерывами, количеством сессий и автостартом.
  - Интервальный тренер: разминка / работа / отдых / заминка / количество раундов.
- **Точная логика времени**:
  - Расчёт по `performance.now()`, а не простое уменьшение счётчика раз в секунду.
  - Меньше дрейфа при задержках браузера.
- **Гибкая настройка времени**:
  - Ручной ввод минут и секунд.
  - Быстрые пресеты: `5`, `15`, `25 (Pomodoro)`, `50` минут.
  - Пользовательские пресеты с минутами и секундами, редактированием, сортировкой, сохранением в браузере и безопасным рендерингом.
- **Удобное управление**:
  - `Старт`, `Пауза`, `Сброс`, `Круг`.
  - Горячие клавиши: `Space`, `R`, `L`, `T`, `F`, `1–4`.
- **Визуальная индикация**:
  - Круговой прогресс-бар.
  - Крупный цифровой дисплей.
  - Подпись текущей фазы для Pomodoro и интервалов, цветовая индикация фаз.
- **Дополнительные функции**:
  - Список кругов.
  - История завершённых сессий, статистика за сегодня и 7 дней, экспорт/импорт JSON и очистка истории.
  - Переключение светлой/тёмной темы.
  - Сохранение настроек в `localStorage`.
  - Несколько звуковых сигналов с регулировкой громкости и тестовой кнопкой.
  - Вибрация на поддерживаемых мобильных устройствах.
  - Браузерные уведомления после разрешения пользователя.
  - Голосовые подсказки, фокус/fullscreen-режим и Wake Lock на поддерживаемых устройствах.
  - Восстановление активного таймера после перезагрузки страницы с ограничением частоты записи runtime-состояния.
- **PWA и offline**:
  - `manifest.webmanifest`.
  - Service Worker со стратегией stale-while-revalidate, offline fallback, уведомлением о новой версии и кэшированием модулей приложения.
  - SVG-иконка приложения без бинарных ассетов.
- **Адаптивный и доступный интерфейс** для десктопа и мобильных устройств.

## 🚀 Быстрый старт

1. Склонируйте репозиторий или скачайте файлы.
2. Откройте `index.html` в любом современном браузере.

> Для PWA/offline-функций лучше запускать приложение через локальный веб-сервер, потому что Service Worker не регистрируется из `file://`.

Пример локального запуска:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Space` | Старт / пауза |
| `R` | Сброс |
| `L` | Добавить круг |
| `T` | Переключить тему |
| `F` | Переключить фокус/fullscreen-режим |
| `1–4` | Выбрать один из быстрых пресетов |

## 🎯 Для чего подходит

- Фокус-сессии и Pomodoro.
- Тренировки и интервальные задачи.
- Учёба, работа и контроль времени в повседневных делах.
- Отслеживание кругов и длительности повторяющихся действий.

## 📌 Примечания

- Если звуковой сигнал не воспроизводится, убедитесь, что браузер разрешает звук для текущей вкладки и страница уже получила пользовательское взаимодействие.
- Браузерные уведомления требуют отдельного разрешения пользователя.
- История, пресеты и настройки сохраняются локально в браузере и не отправляются на сервер.
